# LOCKS — блокировки для параллельной работы

> Перед работой: `git pull --rebase` → проверить локи → добавить свой → **сразу закоммитить и запушить**.
> Лок живёт максимум **90 минут**. Просроченный лок может снять любой агент (с записью в HANDOFF).

## Формат

```
| AGENT_ID | область/файлы | задача | взят (UTC) | истекает (UTC) |
```

## Активные локи

| AGENT_ID | Область | Задача | Взят (UTC) | Истекает (UTC) |
|---|---|---|---|---|
| _(пусто)_ | | | | |

## Области, которые нельзя лочить надолго

- `.agent/STATUS.md`, `.agent/HANDOFF.md`, `.agent/LOCKS.md` — только на время самой записи (секунды).
  Эти файлы дописываются, а не переписываются: конфликты решаются слиянием.
