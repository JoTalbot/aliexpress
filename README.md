# AliExpress Refund Research Project

Исследовательский репозиторий по теме **возвратов средств (refund) и споров (dispute) на AliExpress**.

Проект ведётся **несколькими ИИ-агентами с разных машин, в том числе параллельно**.
Прежде чем что-либо делать — прочитай **[AGENTS.md](AGENTS.md)**. Это обязательно.

## Быстрый старт для агента

```bash
git pull --rebase
cat AGENTS.md            # правила работы
cat .agent/STATUS.md     # что происходит прямо сейчас
cat .agent/TASKS.md      # очередь задач
cat .agent/HANDOFF.md    # последняя передача контекста
cat .agent/LOCKS.md      # что уже занято другим агентом
```

## Структура

| Путь | Назначение |
|---|---|
| `AGENTS.md` | Конституция проекта: правила для всех агентов |
| `.agent/STATUS.md` | Живой статус: кто, что, когда, где остановился |
| `.agent/HANDOFF.md` | Журнал передачи контекста между сессиями/агентами |
| `.agent/CONTEXT.md` | Накопленная база знаний и выводов проекта |
| `.agent/TASKS.md` | Бэклог и канбан задач |
| `.agent/DECISIONS.md` | Журнал решений (ADR) |
| `.agent/LOCKS.md` | Механизм блокировок для параллельной работы |
| `docs/SCOPE_AND_ETHICS.md` | Границы проекта: что делаем, чего не делаем |
| `research/` | Результаты глубокого исследования |
| `tools/` | Утилиты (трекер дедлайнов споров, скоринг товаров) |

## Границы проекта

Проект исследует возвраты как **потребительское право и как явление рынка**
(включая анализ теневой «рефанд-индустрии» с позиции threat intelligence).
Проект **не производит** инструкции, шаблоны доказательств, списки «магазинов-однодневок»
или инструменты для мошеннического получения товаров бесплатно.
Подробности и обоснование — в [`docs/SCOPE_AND_ETHICS.md`](docs/SCOPE_AND_ETHICS.md).
