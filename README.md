# AliExpress Refund Research & Ops

Рабочий проект по **возвратам средств (refund) и спорам на AliExpress**:
исследовательская база + работающие инструменты учёта.

Профиль владельца: **покупатель + рефандер + дропшиппер**, Украина.
Маршруты: прямая доставка UA, локальные склады UA, пересылка через ЕС, дропшиппинг.

Проект ведут **несколько ИИ-агентов с разных машин, в том числе параллельно**.
Прежде чем что-либо делать — прочитай **[AGENTS.md](AGENTS.md)**.

---

## Восстановление проекта в новом окружении

Окружение агента одноразовое. Всё состояние живёт в GitHub:

```bash
git clone https://github.com/JoTalbot/aliexpress.git && cd aliexpress
export GITHUB_TOKEN=<токен>          # или export VAULT_PASSPHRASE=<пароль от vault>
./scripts/bootstrap.sh
```

`bootstrap.sh` настроит git, подтянет изменения, проверит инструменты
и покажет текущий статус проекта с порядком чтения.

**Сохранение работы** (использовать каждые 10–15 минут):

```bash
./scripts/save.sh "research(dispute): описание изменения"
```

## Инструменты

| Инструмент | Что делает |
|---|---|
| `tools/order_ledger.py` | **Основной.** Заказы: дедлайны BP, P&L, разрыв оборотки, экспорт CSV |
| `tools/listing_risk_score.py` | Скоринг листинга по возвратопригодности до покупки |
| `tools/dispute_deadline_tracker.py` | Лёгкий трекер только дедлайнов |
| `scripts/vault.sh` | Хранилище секретов, AES-256 |
| `scripts/bootstrap.sh` | Восстановление окружения |
| `scripts/save.sh` | Коммит + push одной командой |

```bash
# завести заказ в день отправки
python3 tools/order_ledger.py add --id AE-1001 --title "TWS наушники" \
    --cost 12.40 --shipped 2026-08-01 --free-return --route dropship --sold 29.90

python3 tools/order_ledger.py deadlines --days 7   # что горит
python3 tools/order_ledger.py pnl                  # прибыльность
python3 tools/order_ledger.py exposure             # зависшие деньги
```

## Границы проекта

Проект работает с возвратами как с **потребительским правом** и анализирует
теневую «рефанд-индустрию» с позиции threat intelligence.
Проект **не производит** шаблоны ложных заявлений, инструменты фабрикации доказательств
и списки «товаров под гарантированный рефанд» — обоснование в
[`docs/SCOPE_AND_ETHICS.md`](docs/SCOPE_AND_ETHICS.md) (ADR-002, ADR-003).
