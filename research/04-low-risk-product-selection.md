# 04 · Методика отбора товаров с максимальной защитой возврата

**Актуально на:** 2026-08-17 · **Автор:** arena-agent-sandbox-20260817-1152 · **Задача:** T-007

---

## Постановка

Это ответ на запрос «находить товары для рефанда» в его **легальной трактовке**:
находить позиции, где при реальной проблеме деньги вернутся с наибольшей вероятностью
и наименьшими издержками. Иначе говоря — отбор по **возвратопригодности**, а не по «уязвимости».

## 1. Модель риска сделки

Ожидаемая потеря по заказу:

```
E[потеря] = P(проблема) × Сумма × (1 − P(вернут деньги | проблема)) + Издержки возврата
```

Управляемых рычага три:
- **P(проблема)** ↓ — рейтинг магазина, объём продаж, качество отзывов с фото;
- **P(вернут)** ↑ — Free Return, Choice, оплата с чарджбэком, дисциплина доказательств;
- **Издержки** ↓ — локальный склад, предоплаченная этикетка, сумма ниже порога «возврата без отправки».

## 2. Скоринг листинга (используется в `tools/listing_risk_score.py`)

### Сигналы защиты (плюсы)

| Сигнал | Вес | Комментарий |
|---|---|---|
| Бейдж **Free Returns** | +30 | сильнейший одиночный фактор |
| Бейдж **Choice** | +15 | логистика платформы, проверяемая доставка |
| Локальный склад/отгрузка из страны покупателя | +15 | возврат внутри страны |
| Магазин старше 3 лет | +10 | не однодневка |
| Рейтинг магазина ≥ 4.7 при значимом обороте | +10 | статистическая надёжность |
| ≥ 1000 продаж у листинга | +8 | товар массово проверен |
| Отзывы с реальными фото покупателей | +8 | описание совпадает с реальностью |
| Подробная размерная таблица/спецификация | +5 | лишает продавца аргумента в споре |
| Оплата картой/PayPal с возможностью чарджбэка | +5 | внешний рычаг |

### Сигналы риска (минусы)

| Сигнал | Вес | Комментарий |
|---|---|---|
| Магазин младше 6 месяцев | −20 | риск исчезновения |
| Рейтинг < 4.3 | −15 | системные жалобы |
| Обезличенный листинг (generic-фото, коды в вариантах) | −30 | признак hidden link, защита ослаблена |
| Цена аномально ниже рынка (> 60% дисконта) | −15 | классический маркер обмана |
| В отзывах повторяется одна и та же претензия | −15 | системный дефект |
| Нет размерной таблицы у одежды | −10 | спор по размеру не выиграть |
| Товар из категории с ограничением обратной пересылки | −10 | батареи, жидкости, аэрозоли |
| Сумма > $100 без Free Return | −20 | при споре потребуют отправку в Китай |
| Только предоплата экзотическим методом | −15 | нет внешнего рычага |

**Интерпретация:** ≥ 50 — низкий риск; 20–49 — приемлемо с дисциплиной доказательств;
< 20 — покупать только на сумму, которую не жалко потерять.

## 3. Отбор продавца

Практические маркеры, подтверждённые сообществом `[СООБЩЕСТВО, консенсус]`:

- **Возраст магазина** важнее рейтинга: новые магазины могут просто исчезнуть.
- **Объём продаж за 180 дней** — живой индикатор, в отличие от накопленного рейтинга.
- **Читать негативные отзывы, а не средний балл.** Если жалобы повторяют одно и то же —
  это свойство товара, а не случайность.
- **Отзывы с фото** — единственный способ увидеть реальный товар.
- **Тестовый диалог до покупки:** задать вопрос по характеристикам. Ответ фиксирует
  обещание продавца письменно — это потом становится доказательством в споре.

## 4. Пороги сумм — тактика

`[СООБЩЕСТВО]` Наблюдаемая закономерность: чем дешевле позиция, тем выше вероятность
решения «возврат без отправки товара» — платформе невыгодна логистика.
Конкретные цифры в источниках расходятся (называют и ~$5, и ~$30), поэтому:

- дробить крупные закупки на отдельные заказы у разных продавцов имеет смысл
  **не ради схем, а ради независимости рисков**: один проблемный заказ не тянет за собой остальные;
- **дробить и однотипные лоты (T-068):** `[СООБЩЕСТВО]` при частичном браке партии
  в одном заказе платформа требует вернуть **всю позицию целиком** (кейс: 12 ламп,
  2 брака — «верните все 12», частичный возврат недоступен). Партия, разбитая
  на 2–3 заказа, спорится по частям. ⚠ Для UA учитывать таможенный лимит и,
  при EU-forward, сбор €3/строку — дробление заказов не меняет число строк декларации
  при консолидации (`research/13`);
- для дорогой покупки Free Return — не опция, а обязательное условие;
- порог как точную цифру использовать нельзя — порога не существует,
  решает модель по совокупности факторов (✅ закрыто в T-011, `research/09`).

## 5. Категории по возвратопригодности

| Категория | Возвратопригодность | Комментарий |
|---|---|---|
| Одежда/обувь с Free Return | 🟢 высокая | размер — законная причина, этикетка бесплатна |
| Аксессуары, мелкая галантерея | 🟢 высокая | дёшево, обычно refund only |
| Бытовая мелочь, инструмент | 🟡 средняя | важны фото дефекта |
| Электроника среднего ценника | 🟡 средняя | нужны видео тестирования, серийники |
| Дорогая электроника без Free Return | 🔴 низкая | потребуют отправку в Китай |
| Аккумуляторы, вейпы, жидкости | 🔴 низкая | ограничения на обратную пересылку |
| Цифровые товары, коды | 🔴 низкая | покрытие ограничено |
| Персонализированные изделия | 🔴 низкая | исключены из Free Return |

## 6. Предпокупочный чек-лист

- [ ] Есть бейдж Free Returns? (если нет — есть ли причина брать именно этот листинг?)
- [ ] Choice или локальный склад?
- [ ] Магазин старше года, продажи за 180 дней значимые?
- [ ] Прочитаны негативные отзывы, нет повторяющейся системной жалобы?
- [ ] Есть отзывы с фото?
- [ ] Есть размерная таблица/полная спецификация? Скриншот сделан?
- [ ] Оплата методом с чарджбэком?
- [ ] Сумма приемлема к потере, если всё пойдёт не так?
