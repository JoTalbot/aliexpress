## 2. Сообщества (живой опыт)

| Площадка | Ценность | Оговорка |
|---|---|---|
| **r/Aliexpress** (Reddit) | лучший источник практики: FAQ по BP/спорам, свежие треды по Free Return, кейсы банов | выборка смещена в сторону проблем; успешные покупки не пишут |
| Профильные Telegram-каналы (RU) | быстрая реакция на изменения политики | много теневого контента и рекламы «реф-услуг» |
| Facebook-группы по hidden links | структура канала реплик | преимущественно коммерческие посредники |
| Trustpilot AliExpress | агрегированное настроение | сильное смещение к негативу |
| Форумы дропшипперов | взгляд со стороны продавца/реселлера | другая мотивация, но полезная механика |

### Особо ценные треды r/Aliexpress
- Закреплённый FAQ по Buyer Protection и спорам — базовый конденсат.
- «Aliexpress won't refund» — тактика отклонения предложений продавца.
- «Free Return is truly a huge LIE» (2025) — реальное качество исполнения программы.
- «Dispute closed with no refund» — ловушка дорогой обратной пересылки.
- «Just got banned for opening too many disputes» — формулировки деактивации.
- «Pro tip for refund» — приём немедленной эскалации к платформе.

## 4. Вторичные обзоры (использовать с осторожностью)

alixblog, megabonus, dsers, astools, alibestfinds, bayexp, aliexpert.com.ua, ali-shop.net.

Проблема: массово переписывают друг у друга цифры сроков и порогов, часто без даты
и без указания региона. Годятся для понимания структуры процесса, **не годятся**
как источник точных значений. Любую цифру оттуда помечать `[TODO: проверить]`.

## 5. Технические источники

| Источник | Применимость |
|---|---|
| AliExpress Open Platform (`aliexpress.trade.*`) | API для продавцов/аффилиатов; покупателю бесполезно |
| GitHub-скраперы товаров (bivex, ducdev, ParthS007 и др.) | сбор данных листингов для скоринга; требуют своих ключей или Selenium |
| RapidAPI-обёртки AliExpress | быстрый прототип сбора карточек, платно |

Для задачи скоринга листингов (T-012) практичнее всего разбор публичной карточки товара,
а не официальный API.

## 6. Методические правила работы с источниками

1. Официальное правило > массовый опыт сообщества > единичный отзыв > вывод агента.
2. Любая цифра срока/порога без даты и региона считается непроверенной.
3. Reddit-консенсус (десятки согласных комментариев в разных тредах) — сильный сигнал
   о **фактической практике**, даже если противоречит написанному в правилах.
4. Теневые источники цитируются как объект изучения, их содержимое не переносится (ADR-003).
5. Каждый новый источник — в этот файл, с оценкой типа и ценности.
