## 1. Reddit (r/Aliexpress) — главный EN-барометр

Свежие устойчивые темы (2025 — начало 2026):

1. **Волна «blanket rejections»** — с конца 2025 до середины января 2026 всплеск жалоб
   на отказы по спорам «без объяснений», ощущение «платформа по умолчанию за продавца».
   `[СООБЩЕСТВО, массово]` Согласуется с трендом ужесточения из `research/09` — тренд
   не только не развернулся, но усилился.
2. **«Free Return is a LIE»-треды**: обещанная этикетка не генерируется; продавцы
   загружают **пустые/невалидные этикетки**, платформа их не проверяет; покупатель
   в цикле «ожидаем возврат» платит пересылку сам (кейс: £45 почтовых за 2 позиции
   без компенсации). `[СООБЩЕСТВО]` → Новый режим отказа для `research/03`:
   **проверять валидность этикетки сразу** и фиксировать скриншотом.
3. **Требование видео растёт**: unboxing-видео с этикеткой требуют уже и для
   не-электроники и мелочёвки. `[СООБЩЕСТВО]` Наш `UNBOXING_CHECKLIST` и `evidence_pack`
   попадают в тренд — видео одним дублем становится обязательным минимумом.
4. **Частичный возврат после одобрения полного**: кейсы, когда после согласованного
   Free Return продавец оспаривает причину и платформа выдаёт 50%. `[ЕДИНИЧНО→повторяется]`
5. **Партии с частичным браком**: «купил 12 ламп, 2 брак — требуют вернуть все 12,
   частичный возврат недоступен». `[СООБЩЕСТВО]` Практический вывод: крупные лоты
   дробить на несколько заказов — каждый спорится отдельно.
6. Заявленные платформой изменения 2026 (усиленная медиация по fake-tracking, ограничения
   по цифровым товарам, упрощённый refund-без-возврата для <$5): пока подтверждены только
   вторичным обзором `[ВТОРИЧНО, TODO: наблюдать в кейсах]` — с практикой из п.1 сочетается плохо.

## 3. Telegram-экосистема: три слоя

**Слой 1 — скидочно-аффилиатный** (массовый, легальный): «находки», промокоды, купоны.
Десятки каналов, почти все живут на партнёрских ссылках → **подборкам не доверять**
как «проверке качества»: канал получает процент с покупки, а не отвечает за товар.
Для UA есть локальные: промокоды-UA, групповые покупки, новости площадки для Украины.
`[СООБЩЕСТВО]` — [aliexpert: TG-каналы UA](https://aliexpert.com.ua/ru/aliexpress-telegram-kanal/) — 2026-08-17

**Слой 2 — чаты взаимопомощи** (полезный): живые вопросы по спорам, доставке, промо;
UA-чат взаимопомощи существует. Ценность — свежие кейсы исходов споров быстрее, чем
Reddit; шум высокий. Кандидат в постоянные источники для обновления `research/09`.

**Слой 3 — теневой** (не разбираем): рефанд-сервисы, «товары под рефанд», схемы.
По ADR-003: анализ только как явление — экономика и риски описаны в `research/06`.
Ссылки не публикуем. **Признаки, что канал из слоя 3** (чтобы случайно не втянуться):
гарантии «100% возврат», продажа «методов» за деньги, требование доступа к аккаунту,
«работа под заказ» по конкретным магазинам. Любой из признаков = закрыть и забыть.

## 4. GitHub-экосистема вокруг AliExpress

Проверено по свежим репозиториям (2023–2026):

1. **Почти всё — скраперы для продавцов/дропшипперов**: поиск «winning products»,
   выгрузка цен/вариантов/истории заказов. Половина — обёртки коммерческих API
   (RapidAPI, Oxylabs, omkar.cloud) с бесплатными лимитами; остальное — Puppeteer/Python
   парсеры разной степени заброшенности. `[ОТРАСЛЬ]`
   — [oxylabs/aliexpress-scraper](https://github.com/oxylabs/aliexpress-scraper),
   [omkarcloud/aliexpress-scraper](https://github.com/omkarcloud/aliexpress-scraper) — 2026-08-17
2. **Инструментов «стороны покупателя» (дедлайны, споры, P&L) в открытом виде нет** —
   ниша, которую закрывает наш `tools/`. Это подтверждает решение строить своё,
   а не искать готовое.
3. Подтверждение вывода из CONTEXT §2: официальный Open Platform API — для
   продавцов/аффилиатов, покупательских задач не решает.
4. **Скрапинг для наших задач не нужен**: риск нарушения ToS и бана аккаунта (актив
   рефандера/дропшиппера — репутация аккаунта, research/09) несоизмерим с пользой.
   Если владельцу понадобится product-research для дропшиппинга — использовать
   коммерческие API с их лимитами, не самодельный скрапинг под своим аккаунтом.
   `[ГИПОТЕЗА→политика проекта]`
