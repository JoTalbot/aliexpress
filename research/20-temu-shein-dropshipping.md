# 20. Temu и Shein как каналы дропшиппинга: вердикт — нет (T-073)

> Актуально на: 2026-08-17 · Агент: arena-agent-sandbox-20260817-1330
> Связано: `research/15` (сравнение площадок для покупателя), `research/11` (операционка дропшиппера)

## 1. Короткий вердикт

**Temu и Shein — не поставщики для дропшиппинга.** Ни у одной из площадок нет
программы для реселлеров, API или автоматизации фулфилмента; у Temu запрет
на коммерческую перепродажу прямо в ToS. AliExpress остаётся **единственной из
трёх** площадок с официальной поддержкой дропшиппинга (dropshipping center,
интеграции DSers и т.п.). `[ВТОРИЧНО, консенсус всех источников]`

## 2. Temu: почему не работает

| Проблема | Детали |
|---|---|
| Запрещено ToS | коммерческая перепродажа «disrupting the platform»; поддержка Temu прямо подтверждает: программы дропшиппинга нет |
| Нет API/интеграций | каждый заказ — руками с обычного покупательского аккаунта |
| Паттерн = бан | много заказов на разные адреса → алгоритмы флагают аккаунт: бан, заморозка средств, отмены заказов |
| Брендинг | оранжевая упаковка Temu без опции нейтральной — клиент видит источник и цену |
| Возвраты | клиент шлёт **вам**, вы отдельно спорите с Temu; возврат может не принять — убыток ваш |
| Площадки продаж против | Etsy прямо запрещает дропшип с Temu (перманентный бан); Amazon банит за чужую брендированную упаковку |

— [salehoo: Temu dropshipping 2026](https://www.salehoo.com/learn/temu-dropshipping),
[branvas](https://branvas.com/blogs/news/temu-dropshipping-risks-alternatives),
[spocket](https://www.spocket.co/blogs/temu-dropshipping) — 2026-08-17

## 3. Shein: то же, плюс копирайт

Официальной поддержки нет; серые схемы работают «пока не заметили». Дополнительно:
**фото и описания Shein нельзя использовать легально** (копирайт), посылки приходят
в фирменных пакетах с инвойсом Shein. `[ВТОРИЧНО]`
— [cjdropshipping: Shein guide](https://cjdropshipping.com/blogs/dropshipping-knowledge/Shein-Dropshipping-Guide) — 2026-08-17

## 4. Контекст 2025–2026: конец de minimis в США

Если целевой рынок дропшиппинга — США: беспошлинный порог $800 **приостановлен**
(02.05.2025 для КНР/Гонконга, 29.08.2025 — для всех стран; на середину 2026 возврата
нет). Модель «дёшево из Китая напрямую клиенту в США» потеряла главное преимущество —
это бьёт по всем трём площадкам одинаково. `[ВТОРИЧНО]`
Для ЕС аналогично — €150 отменён (наш `research/13/14`). Украина — пока лимит жив (T-040).

## 5. Что Temu/Shein реально дают дропшипперу

Единственное легитимное применение — **разведка спроса**: трендовые товары,
цены-ориентиры, у Shein — фэшн-тренды. Валидация ниши до закупки. Как канал
фулфилмента — нет.

## 6. Решение для проекта

1. Канал фулфилмента дропшиппинга — **AliExpress** (официальная поддержка) и/или
   специализированные поставщики (CJdropshipping, Spocket и т.п. — отдельная тема,
   если владелец захочет сравнение).
2. Temu/Shein — только research-инструмент. Попытки серого дропшипа с них
   в проект не берём: риск потери аккаунтов и платёжных шлюзов несоизмерим.
3. `research/15` (Temu лучше для **покупателя** по возвратам) не противоречит
   этому выводу: покупательская защита ≠ пригодность как поставщика.
