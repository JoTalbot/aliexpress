# secrets/ — хранилище секретов

## Правила (нарушение = инцидент)

1. **Открытым текстом в репозиторий не попадает ничего.** Только `vault.enc`.
2. **Мастер-пароль не коммитится никогда** — ни в код, ни в CI, ни в документацию.
3. Расшифрованные файлы держатся только в `/tmp` и удаляются сразу.
4. Токен, засветившийся в чате/логе/скриншоте, считается **скомпрометированным** и подлежит отзыву.

## Работа

```bash
./scripts/vault.sh init          # создать (один раз)
./scripts/vault.sh edit          # редактировать
./scripts/vault.sh show          # посмотреть
eval "$(./scripts/vault.sh export)"   # загрузить в окружение
```

Пароль: интерактивно или через `VAULT_PASSPHRASE`.

## Шифрование

AES-256-CBC, PBKDF2, 240000 итераций, соль. Стандартный OpenSSL — расшифровывается
где угодно, без установки дополнительного софта:

```bash
openssl enc -d -aes-256-cbc -pbkdf2 -iter 240000 -in secrets/vault.enc
```

## Восстановление в новом окружении

```bash
git clone https://github.com/JoTalbot/aliexpress.git && cd aliexpress
export VAULT_PASSPHRASE='<мастер-пароль>'
eval "$(./scripts/vault.sh export)"
```

## Если пароль утерян

Данные не восстановить. Пересоздать: `rm secrets/vault.enc && ./scripts/vault.sh init`,
затем перевыпустить все токены заново.
